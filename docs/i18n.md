# i18n — jazykové mutace appky

Fáze 1 (hotová): všechny texty UI v `app.js` jsou v jediném slovníku `TEXTS`
a jdou přepsat jazykovým packem. Čeština je **zdroj pravdy** — žije přímo
v `TEXTS`, žádný externí soubor pro ni neexistuje a appka funguje beze změny.

## Jak to funguje

1. **Jazyk UI** se čte z `<html lang="…">` (konstanta `LANG` v app.js).
2. **Jazykový pack** je obyčejný script načtený PŘED `app.js`, který nastaví
   `window.LANG_PACK`. Bez packu appka jede česky.
3. `t(key, …args)` nejdřív hledá klíč v `LANG_PACK.texts`, pak v `TEXTS`.
   Nepřeložený klíč tiše spadne na češtinu — mutace může vznikat postupně.
4. **Data** (`verbs.json`) se nepřekládají v souboru, ale mutací po načtení:
   `localizeData()` přepíše `v.cs` (překlad slovesa), `sub.pattern`,
   `sub.rule`, `sub.title` a `sec.title` podle `LANG_PACK.data`.
5. **TTS**: `LANG_PACK.voice` (např. `'pl-PL'`) nastaví hlas pro čtení zadání
   v Car mode. Anglická slovesa mají vlastní výběr hlasu, ten se nemění.

## Formát packu

```html
<!-- v <head> jazykové mutace, PŘED <script type="module" src="app.js"> -->
<script src="lang/pl.js"></script>
```

```js
// lang/pl.js
window.LANG_PACK = {
  voice: 'pl-PL',
  texts: {
    // Hodnota smí být: řetězec | funkce (parametrizovaný text) | pole (pool
    // hlášek) | objekt { pro, student } (stylové varianty jako v TEXTS).
    resume_continue: 'Kontynuuj',
    plur_verbs: (n) => (n === 1 ? 'czasownik' : (n >= 2 && n <= 4 ? 'czasowniki' : 'czasowników')),
    remaining_of: (n, total) => `zostało ${n} z ${total}`,
    // Pooly hlášek (fb_pass_ok, fb_finale_wrong, fb_streak…) klidně jako pole:
    fb_pass_ok: ['Świetnie! ✅', 'Dokładnie tak. 🚀'],
    // wv_app_labels: celá mapa názvů aplikací pro webview banner (bez t()):
    wv_app_labels: { other: 'aplikacji zewnętrznej' },
  },
  data: {
    verbs: { begin: 'zaczynać', break: 'łamać', /* …všech 106, klíč = infinitiv */ },
    groups: { '1.1.0': { pattern: '…', rule: '…' }, /* …všech 24 */ },
    sections: { '1.0.0': '…', '2.0.0': '…', '3.0.0': '…' },
  },
};
```

## Co je česky specifické (mutace musí dodat vlastní verzi)

- **Pluralizace**: `plur_verbs`, `plur_groups`, `plur_days_row`, `plur_day` —
  funkce (n) => tvar slova.
- **`czAdj` klíče**: `slaba_sub_mixed` / `slaba_sub_clean` používají české
  skloňování; pack je přepíše vlastními funkcemi bez `czAdj`.
- **Styly pro/student/hantec**: hantec je brněnský vtip — mutace typicky dodá
  jen jeden tvar (prostý řetězec platí pro všechny styly), případně vlastní
  dvojici pro/student.
- **Pooly hlášek** (`POS_*`/`NEG_*`/`STREAK_*` přes klíče `fb_*`): přepsat
  polem lokálních hlášek; `{name}` v textu se nahradí křestním jménem.

## Fáze 2 (hotová pro pl): mutace = adresář s vlastním index.html

První mutace je polská a žije v `/pl/`:

- **`lang/pl.js`** — kompletní pack: `voice: 'pl-PL'`, všechny klíče z `TEXTS`
  (včetně polských plurálů a stylových poolů pro/student — hantec spadá na
  pro), `data` s překlady všech 106 sloves, 24 skupin a 3 sekcí.
- **`pl/index.html`** — ručně přeložená kopie root `index.html`. Klíčový trik:
  `<base href="/">`, díky kterému z `/pl/` fungují relativní cesty uvnitř
  app.js (`fetch('data/verbs.json')`, `register('sw.js')`) i sdílené assety.
  Odkazy patřící mutaci proto musí mít prefix `pl/` (manifest). Hantec
  (brněnský vtip) je v polské mutaci vynechaný — tlačítka jsou v app.js
  null-guarded, chybět můžou.
- **`pl/manifest.json`** — `start_url`/`scope` = `/pl/`, ikony absolutně.
- Root `index.html` se při úpravách musí promítat do `pl/index.html` ručně
  (generátor zatím není — vznikne, až bude mutací víc).

## Co zůstává neřešené

- **SEO stránky** (`/skupina/*`, `/pro-skoly/`, `sitemap.xml`), hreflang
  provázání a PDF přehled.
- **Ceny** — mechanismus pro lokální měnu už existuje: pack může dodat
  `stripePrices` (přepíše `STRIPE_PRICES` v app.js) a jazyk Stripe Checkoutu
  se posílá backendu (`locale`, whitelist v server.js). Chybí jen samotné PLN
  prices v Stripe dashboardu — pak odkomentovat blok v `lang/pl.js` a přepsat
  zobrazené částky v `pl/index.html`.

## Jak ověřit, že mechanismus žije

Dočasně vlož do `index.html` před `app.js` script s testovacím
`window.LANG_PACK` (viz výše) a zkontroluj, že se přepsané texty ukazují
a nepřepsané zůstávají česky. Testováno 2026-07-11 (mini polský pack).
